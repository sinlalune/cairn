# Project plane

Durable execution state: one folder per coding path under `coding-paths/`,
the journal of integrated outcomes under `log/`, and the provisional notes of
the first two stages under [`brainstorm/`](./brainstorm/index.md). A path's opening acceptance
and resume section live in its `index.md`; its closing review is the pull
request. `sessions/` holds the one opening record written before the
acceptance moved inline, kept as history.

Git keeps this plane's history.
