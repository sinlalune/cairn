# Project plane

Durable execution state: one folder per coding path under `coding-paths/`, and
the journal of integrated outcomes under `log/`. A path's opening acceptance
and resume section live in its `index.md`; its closing review is the pull
request. `sessions/` holds the one opening record written before the
acceptance moved inline, kept as history.

The companion history is [log.md](./log.md).
