# CP-CAIRN-006 S07

### S07 — every refusal names its remedy — **COMPLETE**

#### Plan

ADR-008 decision 6, one subject: what a refusal tells the person who
reads it. Every blocking message says what to do in the same sentence
that says what is wrong — because three times on the adopter a message
that named a fact led the agent to move the fact. A rewritten
`base_commit`, an edited step record, a widened `writes:`: each was the
remedy a message that stopped at the fault invited.

**The sweep is over the messages, not the rules.** Every
`add('blocking', …)` in `tools/cairn-check.mjs`, and every message the
pure error functions produce, since those reach the reader through
`${error}` — `pathFrontmatterErrors`, `transitionErrors`,
`workUnitErrors`, `closingAcceptanceErrors`, `openingAcceptanceErrors`,
`adrFrontmatterErrors`, `closureFieldErrors`, `dispositionErrors`. Two
remedies recur and are stated wherever they apply: **a pushed record is
corrected by a superseding step, never by editing it**, and **an object
id the checker computes is never typed to satisfy it**.

**Three messages are known to be wrong, not merely silent.**
`registration-base` says only that `base_commit` is not the parent of the
registration commit — the message the adopter answered by rewriting the
field to a value the specification calls false, and the message ADR-004
decision 1 names as owed a remedy. `work-unit`'s type error is the one
that met `review` and produced an edited pushed record, and ADR-008
decision 6 writes out the sentence it should have carried.
`provisional`'s *fold each into the work unit it was drafting* is
impossible where this host forbids rewriting: the remedy is the later
unit that finishes the draft, which S05 taught the rule to read.

**The citations under `tools/`.** Seventeen comments cite `CP-OPS-002`,
`CP-UI-TYPOGRAPHY` and Atomik — an earlier repository's records, which a
reader here cannot open. Each becomes the fact it was evidence for,
citing this repository's own record where one exists and no id where
none does.

Definition-of-done item advanced: the seventh, with the ninth's first
half — the stale citations.

Type `implementation`: the messages are behaviour, and the fixtures that
assert on them come first.

Deliberately not in this unit: the `review` rule and the fixture sweep of
ADR-004 decision 4 (S08); `docs/modules/application.md` describing the
tools as they are, which S08 writes once the last rule exists; the
skills' own messages, row 1's surface.

- **An audit that holds the rule to itself.** A test reads the checker's own

  asks the same of each sentence. The decision is a predicate now, not a
  reviewer's memory, and it found fifteen silent messages to start with.
- **The three refusals that taught an agent to move the fact.**
  `registration-base` said only that `base_commit` was not the parent of the
  registration; it now says which commit the registration is, and that
  registering again is the repair where rewriting the field is not.
  `work-unit`'s type error met `review` on the adopter and the agent edited the
  pushed record; it now carries ADR-008 decision 6's own sentence. And
  `provisional` told a no-rewrite host to fold — the one remedy this
  repository forbids — where the resolution is the later unit that finishes the
  draft, which S05 taught the rule to read.
- **Forty-odd messages rewritten**, each keeping its fault and gaining its
  remedy: the vocabularies say which value to declare and why that set is
  closed; the computed ids — `base_commit`, `subject_commit`, the checkpoint,
  the digest — say where the value is read from, so none is typed to satisfy a
  gate; the void candidate says the candidate is void.
- **The fixtures assert on the remedy**, as ADR-008 decision 6 asks:
  `fixture` and `pathFixture` take the pattern their refusal owes, and the two

- **Ten dangling citations** of an earlier repository's records — `CP-OPS-002`,
  `CP-UI-TYPOGRAPHY`, and four `Atomik S…` — became the facts they were

#### Review

First read, a fresh context given this unit's diff and the two criteria, and
nothing else. Thirteen findings; each with its disposition:

- `correctness:` the `registration-base` remedy I wrote instructed a repair
  this model cannot perform — *register the path again*, where the registration
  is the earliest trunk commit declaring `running` and is immutable, while the
  only other move it named was one it forbade. A refusal with no achievable
  action, in the one message ADR-004 decision 1 rewrote for exactly that reason
  — **fixed**: the rule returns the registration and the parent it computed,
  and the message prints them, which is ADR-008 decision 6's own second remedy
  (an id the checker computes is never typed to satisfy it).
- `correctness:` the audit tested punctuation, not a remedy. Any `— ` or `; `
  satisfied it, and it passed `ready requires exactly one administrative
  commit; found N`, which names no remedy at all — the test's own guarantee was
  false in the file it audits, on the day it was written — **fixed**: it reads
  for an imperative verb from the list these remedies actually use. A message
  can still satisfy it with bad advice; it cannot satisfy it while saying
  nothing. Nine more silent messages surfaced when it did.
- `correctness:` the pure half omitted `dispositionErrors`, `routeDescent` and
  `fillErrors`, whose sentences reach the reader through an interpolation the
  first half skips — about a dozen remedy-free sentences went unaudited —
  **fixed**, all three are called, and every one of their sentences gained a
  remedy.
- `correctness:` the ternary handling joined both branches into one string, so
  a silent branch passed on a talkative sibling's coat-tails — the case this
  unit had just introduced — **fixed**: each branch is read alone, with a named
  exemption for a grandfathering branch, which is an explanation on purpose
  because its reader has nothing to do.
- `correctness:` `transitionErrors`' fallback said *this state is terminal* for
  a status outside the vocabulary, where the previous status was simply garbage
  — **fixed**.
- `correctness:` the blocking `provisional` message now said a no-rewrite host
  never folds while the advisory three lines below still said *must be folded*
  — a split this unit created — **fixed**, both read the host's policy.
- `delete:` a test block asserting nothing over a state that cannot exist —
  **fixed**, see the self-review.
- `delete:` a dead regex alternation — **fixed**.
- `shrink:` five over-long remedies — **fixed**.
- `shrink:` two hardcoded counters — **fixed**; the owner's rule is that a
  count is measured and reported, never asserted.
- `shrink:` three `fillErrors` calls where one binding does — **fixed**.
- `correctness:` no string-escaping or template-literal defect, and the changed
  assertions still fail on regression — **noted**.
- `shrink:` *Brought over from the first adopter at 46bdd11* keeps a commit id
  belonging to a repository the sentence no longer names — **fixed** by
  restoring the name: a provenance line with an id is a citation a reader can
  follow, which is what this unit kept elsewhere and should not have
  de-identified here.

Second read, a fresh context given only the diff of those fixes and the same
two criteria, as ADR-017 decision 3 bounds it. Thirteen findings:

- `correctness:` the `registration-base` remedy I had just written still told
  the writer to type a computed id — the very thing ADR-008 decision 6 names as
  the recurring wrong answer, and what ADR-004 decision 1 calls a value false by
  the specification's own definition. It also asserted the parent *is* the
  branch point, which a mismatch is precisely evidence against — **fixed**: the
  message prints what it compared, names `git merge-base` as the question, and
  names both repairs — the field read from the wrong commit, or a branch created
  before registration, which `spec/reference/repair.md` already covers. Neither
  is "write this to go green".
- `correctness:` the per-branch audit was inert and could only weaken the check
  — `!namesARemedy(skeleton) && !namesARemedy(branch)` cannot add a finding the
  whole message would not already produce — and the grandfathered `continue`
  skipped entire messages when the exempt literal was the only one extracted,
  leaving one live message unaudited — **fixed by deleting it**: the audit reads
  a message whole, and the test states what that does not prove. Telling a
  ternary's branches apart needs a parser, and the branches that differ today
  are a grandfathered explanation and two remedies.
- `correctness:` a remedy held in a `const` beside the message was erased to
  `…`, so the detached-checkout message could only pass by padding — which is
  what my *name it:* did, a proxy paid off with a word — **fixed**: the audit
  expands an interpolation of a name this file binds to a string, and the
  padding is gone. A mutation that guts that `const` now turns the test red.
- `correctness:` *return the record to running* was impossible for two of the
  three statuses the rule fires on: `transitionErrors` refuses `done → running`
  and holds `archived` terminal — **fixed**, the message names what a reader
  can actually do.
- `correctness:` the replacement for the counters was tautological — `every`
  over a possibly empty array — so a producer falling silent would have passed
  — **fixed**: the test names the sentences that must be reached, which is the
  property the counter was standing in for.
- `correctness:` two literal-extraction defects the comment claimed were
  handled — an escaped apostrophe terminating a literal, and a fragment
  spanning a template boundary — **fixed** by extracting with an
  escape-aware scan and unquoting, rather than by a character class that
  guessed.
- `correctness:` the changed data shape has no stale readers — **noted**.
- `shrink:` the `prose`/`branches` machinery is deletable with no loss —
  **fixed**, deleted.
- `shrink:` verbosity moved the wrong way: five messages trimmed and a dozen
  grown — **fixed** on the three worst, and the `advisory_disposition` message
  that repeated `dispositionErrors`' own sentence and demanded more than its
  own gate accepts.
- `shrink:` the `transitionErrors` fallback replaced dead code with
  ungrammatical near-dead code — **fixed**, one sentence that reads whatever
  the previous status was.
- `shrink:` nine of forty-four imperatives matched no message — **fixed**, the
  list is the verbs these remedies use; three I had cut turned out to be used
