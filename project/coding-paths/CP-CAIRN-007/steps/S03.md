# CP-CAIRN-007 S03

### S03 — the gate stops certifying what it cannot see — **COMPLETE**

#### Plan

Take `GITHUB_TOKEN` back out of the checker's step, which
[S02](./S02.md) put there, and say in the workflow why it is absent.

The violation S02 introduced: the gate certified a protection the
repository does not have. The draft request's run `34756757308` on
`1505444` printed

```text
profile — transports registration manual-git, integration pull-request; forge enforces everything these records name
```

while this repository's trunk ruleset `22101008` carries
`bypass_actors: [{actor_id: 5, actor_type: RepositoryRole, bypass_mode:
always}]`. A workflow is given only the forge's own
`secrets.GITHUB_TOKEN`; that token may not read a ruleset's bypass list,
and the forge ELIDES the field rather than refusing it, so
`forgeGaps` reads an absent list as a trunk nobody bypasses. A refusal
would have been reported as *forge not read*. Silence was reported as
safety, on the one run that is the merge gate — which is the opposite of
what the profile line of ADR-001 decision 6 exists to do.

Definition-of-done item advanced: none. It **un-advances** the second,
and the reason is below.

Type `repair`: the corrective change, and this step naming the
violation. No record is superseded — ADR-001 decision 6 still holds, and
what is disproved is an assumption in path 2's journal debt, which this
path's own journal entry will carry.

Deliberately not in this unit: `forgeGaps` and `readForge` in
`tools/cairn-check.mjs`, where the real remedy is — telling an unread
bypass list from an empty one. Item 7 of the definition of done holds
that file byte-identical, and nine assertions of
`tools/cairn-check.test.mjs` are written against the present reading, so
taking it here means editing two files coding path 2 closed and amending
an accepted definition of done. The manifesto's *if the workflow needs a
solution that is not native to those tools, it is most probably not a
best practice* rules out the other way round it as well — a fine-grained
token with an administration scope, stored and rotated as a secret, to
make one line of output true.
