#### Review

First read, a fresh context given this unit's diff — six sentences in
three skills and a template — and the two criteria, the ladder and
correctness, and nothing else. Eleven findings, and the first three are
the reason this movement exists:

- `correctness:` **`depends_on` was written backwards.** The sentence
  said *declare it on the path that lands first*; it goes on the path
  that WAITS. The reader proved it four ways — this skill's own movement
  1, the checker's refusal message, the record, and a fixture named for
  it — and showed the gate would not have caught the mistake, because
  `writesOverlaps` falls silent on either direction. It would have
  marked an already-running path blocked by one that had not started,
  and made the live view's *unblocked* false. It also asked the opening
  writer to edit another path's record, outside their `writes:`.
  **Fixed**: this path declares `depends_on` naming the one it waits for.
- `correctness:` *never two paths in one request* is false of the tool.
  The rule refuses two paths reaching `done` in one COMMIT, and the
  checker says in its own comment why it does not refuse two honest
  integrations in one request — *refusing it would tell the author to do
  what they already did* — with a fixture asserting that green. The
  record's wording is the half the implementation deliberately did not
  adopt, and a skill is what an agent obeys, so the sentence would have
  had a writer refuse what the gate passes. **Fixed**: the skill states
  the refusal the tool makes, and says the other shape is allowed.
- `correctness:` the merge prohibition named the wrong merge. *A merge
  object that brings the trunk in* is the Crumbz incident, not the norm:
  the rule refuses ANY commit where `done` arrives with more than one
  parent, and both fixtures merge the PATH BRANCH into the trunk — the
  shape a `pull-request` writer actually produces, and the one the
  sentence failed to forbid. **Fixed** to the norm, with the remedy the
  checker itself prints.
- `correctness:` that sentence contradicted the one two lines below it,
  which prescribes a `--no-ff` merge carrying the edits on `manual-git`.
  **Fixed**: the norm is stated without a scope it cannot carry, and the
  `manual-git` sentence is left as it was — see the debt below, because
  the contradiction is older than this unit.
- `correctness:` *printed into the run's log AND posted on the request*
