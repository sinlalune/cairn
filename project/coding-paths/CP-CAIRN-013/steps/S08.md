#### Plan

`skills/cairn-close/reference.md`. The block gives the fresh coherence

`cat project/coding-paths/CP-*/index.md`, commented *the paths running
beside it*. The glob matches every path folder — thirteen in this
repository, of which one is running — so it hands that reader every
completed and archived record, and this path's own record with them: the
goal, the tried-and-rejected section, the resume section, the writer's

comment says one thing and the command does another, and the difference
is exactly the independence the read exists for.

reader is given those records, one command per sibling, never this
path's own. The skill's own sentence is unchanged and was already right
— *the records of the paths running beside it*, inside a list closed
with *and nothing else*.

`cairn-close` skill as this path leaves it* is what found this: the
request carried the review, a reader read it, and the defect was caught
before the merge rather than by the first adopter to run the command.
