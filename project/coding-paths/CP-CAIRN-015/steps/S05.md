  of record uses loads skills from a folder, so no other is pinned.

each of the two skills is one `SKILL.md` with no relative link — and
GitHub's answer for the latest release, `v4.10.0`, whose raw file
answers at its tag. The fetch reads the release's tag, then each file at
that tag; `CAIRN_PONYTAIL` names a local copy of the plugin's repository
to read instead, the suite's way of running with no network and an
offline adopter's mirror. `status` never fetches: it plans with the
repository's own copy, so a stance the lock owns is never read as one
that left the kit.
