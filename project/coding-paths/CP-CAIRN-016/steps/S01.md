# CP-CAIRN-016 S01

### S01 — cairn-active writes the register's state cells — **COMPLETE**

#### Plan

`cairn-active` fills every state cell of the roadmap register from the
records and `--check` reports one that disagrees (ADR-031 decision 2);
the register's cells at this unit are the tool's. Not in this unit: the
post-mortem, the audit tool, the workflow, `AGENTS.md`.

Definition-of-done item advanced: the first, in full.

Type `implementation`: the failing test first — `fillRegister` did not
exist, and the command had no register to call stale.

What ADR-031 left to the path, put to the owner as a decision in the
chat of 2026-09-25 and ruled on the recommended options: a milestone
counts the paths its row names and those in the table under the heading
that ends with its short name (`Cairn 1.2` owns *The coding paths of
1.2*), reading `running` while any is not done or a row there has no
path yet, and `done` with its last path's date once all are; a done path
is dated from its journal entry's file name.
