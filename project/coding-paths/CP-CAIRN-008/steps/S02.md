# CP-CAIRN-008 S02

### S02 — the forge reading, and the token back — **COMPLETE**

#### Plan

Make the checker tell a bypass list nobody read from a trunk nobody
bypasses, and give the workflow its token back on the strength of it.

[ADR-026](../../../../docs/adr/ADR-026-the-readings-that-must-not-lie.md)
decision 1 is what this implements: a reading the forge withheld is
reported as unread and never as an answer. `forgeGaps` returns
`{ gaps, withheld }` — a gap is a fact about a setting that was read, a
withheld entry is a reading that was not made; `readForge` stops failing
the whole read when one ruleset is refused and names that half instead;
the profile line prints all three parts when anything was withheld.

Definition-of-done item advanced: the second, in full, and with it item 2
of coding path 3's definition of done, which closed knowingly unmet.

Type `implementation`: the source, its tests, the affected module note
and this step. The withheld case is written first and fails; the nine
`forgeGaps` assertions written against the old array return are rewritten
against the new shape.

Deliberately not in this unit: the `review` and `acceptance` rules (S03),
which share the file but not the reading; the soundness note, whose lines
are per rule and which S03 owns; `docs/modules/application.md` beyond the
paragraph this unit makes false — S05 describes both tools whole.

**Widening of `writes:`**: `tools/cairn-workflow.test.mjs`, added to the
record in this unit. Coding path 3's S03 asserted `GITHUB_TOKEN` absent
from the checker's step; returning the token makes that assertion fail,
so the file that pins the workflow has to move with the workflow. It was
not in the opening scope because the registration listed the workflow and
not the test that reads it.

- **`tools/cairn-check.mjs`**: `forgeGaps` returns `{ gaps, withheld }`;
  a ruleset whose `bypass_actors` is not an array was not read, and is
  named as `the bypass list of ruleset <id>`; the bypass count is taken
  only from the lists that WERE read, so an elided field can no longer
  enter the gaps as an absence of actors. `readForge` passes a ruleset it
  could not fetch as its id alone and returns `{ read: true, gaps,
  withheld }`, instead of throwing away the rules the branch endpoint
  gave to say nothing about the one ruleset it did not. `profileLine`
  prints, where anything was withheld, what was read, what was not, and
  what is unenforced *among what was read* — and never the sentence that
  claims the whole forge.
- **`tools/cairn-check.test.mjs`**: the withheld case first and failing —
  an elided list is `withheld`, an empty list is a reading; the refused
  ruleset rewritten from *fails the whole read* to *is the half that is
  withheld*, asserting that the gap the branch endpoint gave is still
  reported; the nine `forgeGaps` assertions moved to `.gaps`; the profile
  line's withheld case asserting the three parts and the absence of
  *enforces everything*.
- **`.github/workflows/cairn.yml`**: `GITHUB_TOKEN` back in the checker's
  step, with the comment rewritten to say that the token did not change —
  the reading did — and what this token still cannot see.
- **`tools/cairn-workflow.test.mjs`**: the assertion inverted with the
  reason, still on the env KEY rather than the word, as path 3 wrote it.
- **`docs/modules/application.md`**: the paragraph that said no token is
  mapped into the checker's step, which this unit makes false, rewritten
  to the three answers the line now gives.

#### Review

First read, a fresh context given this unit's diff — the checker, its two
test files, the workflow and the module note — and the two criteria, the
ladder and correctness, and nothing else. Nine findings; each with its
disposition:

- `correctness:` `readForge` discarding `answers[i].error`, so a 5xx, a
  timeout or a rate limit read exactly like an elided field, and the
  comment's *the remedy for both is a token that may* was false for the
  transient cases — **fixed**. The reason the forge gave is carried into
  the withheld line, and a test pins the string.
- `correctness:` a ruleset body without `id` reaching the `'unknown'`
  fallback through `readForge`, which holds the id it asked for —
  **fixed**, the id carried through; the fallback is gone with it.
- `correctness:` `profileLine` defending `forge.withheld ?? []` and then
  reading `forge.gaps.length` unguarded, so `{ read: true, withheld: […] }`
  threw — **fixed**, both fields read the same way.
- `correctness:` the module note's *the three gaps that token can see*,
  a count this repository's own run will not print — its trunk rules
  yield no readable gap at all — **fixed**: the note says the run names
  the bypass list as unread and reports whatever the rules do say.
- `correctness:` no end-to-end case for the reading the whole unit exists
  for — an HTTP 200 with `bypass_actors` elided was pinned at `forgeGaps`
  but never through `readForge`, where the hand-off lives — **fixed**, the
  case added and the profile line asserted on it.
- `shrink:` `Array.isArray(ruleset?.bypass_actors)` written twice over
  the same list — **fixed**, one pass that partitions read from unread.
- `delete:` `?? 'unknown'` — **fixed**, cut with the id fix above; the
  line in this step's self-review that kept it is wrong and is superseded
  by this one.
- `shrink:` the 2026-09-13 incident retold six times inside one diff —
  **fixed**, cut from the doc block, which states the shape instead.
- `shrink:` one line of the module note at 118 characters against the
  file's wrap — **fixed**.

Second read, a fresh context given only the diff of those fixes and the
same two criteria, as ADR-017 decision 3 bounds it. Four findings:

- `correctness:` `{ id, why, ...value }` spreading the payload last, so a
  body's own `id` would override the id actually requested — the opposite
  of what the comment above it claimed — **fixed**, the spread first. No
  test saw it because the fixture's id matches what was asked.
- `correctness:` a rule whose `ruleset_id` is null is filtered out of the
  request loop, so its bypass list is never asked for and never withheld —
  the last route by which *forge enforces everything these records name*
  could be printed over a list nobody read — **fixed**, with the
  adversarial case. Pre-existing and outside the fixes; taken because it
  is the defect this unit exists to close, and two lines from where the
  reader found it.
- `shrink:` `forge.gaps ?? []` is unreachable today — **refused**. The
  first read's finding was that the two fields were guarded differently
  and one of them threw; making them read alike is that fix, and reverting
  half of it to save four characters restores the asymmetry that produced
  the crash.
- `shrink:` the inline comment restating the doc block six lines above —
  **fixed**, cut to the two facts the code needs.

The fixes above are not read a third time.
