- **The packaged command could not run.** Importing the configuration
  module loaded the host configuration at module load, and the tarball
  carries none, so every command aborted before parsing its arguments —
  reproduced by packing the commit and running `init` from the extraction.
  The configuration now loads the first time a tool asks for it,
  `installedConfig()`; the checker, the live view and the scaffolder ask at
  their start and fail there with the path named; the command imports only
  the pure validators. A test unpacks the package's file list into another
  repository's `node_modules` and runs `init` from there.
- **The links pinned the wrong commit.** The command derived its source
  commit by asking Git from its own directory, which inside an adopter's
  `node_modules` walks up to the adopter's commit, and outside any worktree
  fell back to the trunk. `prepack` now stamps `tools/release.json` with the
  commit the package is cut from, the command reads it first, asks Git only
  when its directory is the top of a worktree, and says `unknown` — linking
  the trunk, stated as such — otherwise. Packed and run inside another
  repository, `init` pins the stamped commit; the same test asserts an
  unstamped copy never takes the adopter's.
- **`update` could rewrite the adopter's files.** A host file — the
  bootloader, the binding, the workflow, an index, the area note — that the
  adopter had never edited matched its lock digest and was rewritten with
  the new template, and one that left the kit was deleted, though the
  contract said host files are the adopter's from day one. The lock now
  names the host files; `update` writes one only where it is missing, names
  it for review when its template changed, and never deletes one; a lock
  from before host files were named reports everything that left rather
  than deleting. The pure status test covers each case; the update test
  changes the bootloader's template and asserts it is reviewed, not
  written.
- **The site lost anchors.** A link with a fragment routed to the right page
  and the top of it: the route parser dropped everything after the second
  `#`, and no heading carried an id. Routes keep their fragment, every
  heading carries the slug the checker resolves a `scope_ref` anchor by —
  `#definition-of-done` means one thing in a link, in a record and on the
  site — and the page scrolls to the heading after it renders. The pure
  half is a module with a test; the build is the rest.
- **Found while fixing.** The calendar moved during the path, and the
  fixture harness and the pilot dated their records at authoring time: the
  step record's date drifted two days from its adding commit, `record-date`
  said so, and on `manual-git` the closing record had to attest it. The rule
  was right; the harness and the pilot date their records today.
- Rejected: keeping a module-level configuration constant and catching the
  missing file in the command. Every tool would still pay the load on
  import, and a validator that cannot be imported without a host is not a
  validator of a host.
- Rejected: writing the commit into `package.json` at publish time. A
  generated file beside the package's own manifest is a stamp; a manifest
  rewritten by a script is a manifest nobody trusts.
