# CP-CAIRN-003 — forward plan

Read when planning, never before every step. The records follow the four
notes, so a reader holding a note can find the record for any answer; the
1.1 page and the register come last because they name every record.

1. **S01 — ADR-016, the coding stance.** Q1 to Q5: `cairn-code` shrinks to
   what is Cairn's own and the kit points at Ponytail at a pinned tag for
   the ladder and the review (Q2); the self-review speaks in Ponytail's
   five tags (Q1); two lines on secrets and errors (Q4); the ladder and
   correctness as the only criteria of any reader (Q5); no size for a unit
   (Q3, the two other options rejected). Names `skills/cairn-code/SKILL.md`,
   `skills/cairn-unit` step 3, the kit's manifest in `tools/cairn.mjs`.
2. **S02 — ADR-017, the review movement, and ADR-018, two sentences of the
   cycle.** Q6 and Q7: a unit has five movements — plan, change,
   self-review, review, verify — the review being the writer's own agent in
   a fresh context that sees only the diff and the criteria, its findings
   and their dispositions written into a section the checker requires;
   the rule named, the fixture named, the manifesto's test weighed, the
   owner's words on plans and connectors quoted. Q8 and Q9: the failing
   test first when behaviour changes, no new test when only structure
   does; the request's first coherence question answered item by item of
   the definition of done. Names `skills/cairn-unit`, `skills/cairn-close`,
   `spec/reference/path-template.md`, the request template, one new rule
   in `tools/cairn-check.mjs`.
3. **S03 — ADR-019, areas and the architecture page.** Q10 to Q12: an area
   is a folder of the tree; the architecture template asks for the
   direction of dependencies in one sentence; the open skill asks which
   area a path writes in and a path that needs a whole source root says
   why. Names `skills/cairn-open` step 1, the architecture template in
   `tools/cairn.mjs`, `spec/reference/configuration.md`.
4. **S04 — ADR-020, the one edge and the one writer, confirmed.** Q13 to
   Q15: the edge lives in the record only; a path has one writer and a
   helper agent inside the writer's session is the writer, one sentence in
   the unit skill; the register carries no edge between milestones. A
   record of what was weighed and kept, as ADR-008 was.
5. **S05 — the 1.1 page and the register.** The architecture page amended
   with *promoted from* links to the six notes; the index of
   `docs/architecture/` refreshed; the register's rows 1, 2 and 4 carrying
   the new records and surfaces.
6. **S06 — the candidate.** Trunk merged in, gates bare, the request opened
   with the coherence audit as its description, the owner reading the
   pages before the merge.
